# رسمي | Rasmi Drawing Tutor

مشروع Android بلغة Kotlin وواجهة Jetpack Compose، مع واجهة عربية RTL وهوية داكنة بالبنفسجي والفضي.

## المزايا الموجودة في هذا الإصدار 1.2.0
- اختيار صورة من الهاتف عبر منتقي الصور.
- شاشة «Tutorial Ready» بعد التحليل، تعرض الصورة المختارة ومعاينات المراحل وزر بدء الدرس، مع إمكانية إلغاء الاختيار أو استبدال الصورة.
- عرض مراحل معالجة محلية متدرجة للصورة لتسهيل تتبّع الخطوط.
- مكتبة تمارين رسم هندسية أساسية وثلاثية الأبعاد وتمارين للتحكم بالقلم.
- إعداد مفتاح Gemini داخل التطبيق، واختبار الاتصال وطلب إرشادات تعليمية باللغة العربية.
- أيقونة تطبيق بنفسجية.
- GitHub Actions لبناء APK تجريبي عند الدفع إلى `main` أو `master`، أو تشغيل البناء يدويًا.

## البناء من الهاتف عبر GitHub
1. فك ضغط هذا الملف على الهاتف.
2. ارفع محتويات المجلد إلى جذر المستودع `muktdabdr/Zahraa-rasem`، وليس ملف ZIP كمرفق Issue.
3. تأكد أن مجلد `.github/workflows` مرفوع مع بقية الملفات.
4. افتح تبويب **Actions** وشغّل `Build Rasmi Android` أو انتظر تشغيله بعد الدفع.
5. عند نجاح البناء، نزّل `rasmi-debug-apk` من قسم Artifacts في نتيجة التشغيل.

## ملاحظات دقيقة
- لا يتضمن هذا المشروع ملف APK مبنيًا مسبقًا؛ ملف APK ينتجه GitHub Actions.
- مراحل الصورة في هذا الإصدار هي معالجة محلية للخطوط بدرجات مختلفة، وليست رسومات تعليمية دلالية مرسومة يدويًا بواسطة نموذج ذكاء اصطناعي.
- Gemini يعطي ملخصًا وإرشادات نصية؛ لا يُدّعى أنه ينشئ خمس صور مراحل رسم مستقلة.
- مفتاح Gemini يُدخل على الجهاز. لا تضمّن مفتاحًا سريًا ثابتًا في التطبيق عند نشره للعامة؛ استخدم خادمًا وسيطًا آمنًا للإصدارات العامة.


## تحسينات الإصدار 1.2.0
- إضافة شاشة مراجعة قبل بدء الرسم مستوحاة من مرجع التصميم الذي طلبه المستخدم.
- عرض معاينات مراحل الرسم في شبكة واضحة مع ألوان مميزة لكل بطاقة.
- تحديث إصدار التطبيق إلى 1.2.0.
- تغيير اسم نموذج Gemini إلى `gemini-2.5-flash` بدل اسم النموذج السابق الذي قد لا يكون متاحًا.

## تحسينات الإصدار 1.1.0
- تكبير وتصغير مخطط الرسم حتى 5×، مع دعم السحب بإصبع واحد والتحكم بالإيماءة بإصبعين وإعادة ضبط العرض.
- تحكم بشفافية الصورة الأصلية للمقارنة أثناء النسخ.
- اختيار مباشر لمرحلة الرسم من شريط المراحل.
- توسيع مكتبة التمرين إلى أشكال هندسية وطبيعية وحيوانات وملامح بشرية.
- ترتيب المراحل من الهيكل العام إلى المحيط والتفاصيل.

ملاحظة تقنية: مراحل الصورة تُستخرج محليًا من حواف الصورة بدرجات تفاصيل مختلفة؛ هذا ليس فصلًا دلاليًا كاملًا للأجزاء ولا يولّد رسومات تعليمية مرسومة يدويًا بواسطة نموذج صور. Gemini يقدّم تعليمات نصية للصورة عند توفير مفتاح API صالح.
